# warehouse-management-system---excel
نظام إدارة مخازن بالاكسل قابل للتخصيص حسب طبيعية نشاط المخزن 
ملف الاكسل يضم 19 ورقة (Sheet) بتصميم يعتمد على الجداول المنظمة والدوال التلقائية 
لتقليل الإدخال اليدوي المتكرر، الحد من الأخطاء البشرية، وربط حركة المخزون والحسابات والتقارير بشكل فوري وقابل للتخصيص حسب طبيعة نشاط المخزن
